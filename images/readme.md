DON'T PUT ORIGINAL PHOTOS HERE
==============================

Everything in this folder is generated by tools/optimize_images.py.
Full-size camera originals are kept OUTSIDE the repo, in the
ujphotography-originals folder next to this project:

  ujphotography-originals/
    hero1.jpg … hero10.jpg        hero slideshow on the home page
    about.jpg                     about / profile photo
    portfolio/<series>/slide1.jpg, slide2.jpg …
    portfolio/<series>/thumb.jpg  (optional; slide 1 is used if missing)

  <series> = portraiture, landscape, wedding, street, automotive,
             realestate, localbusiness

To add or change photos:
  1. Put / rename the originals in ujphotography-originals/
  2. Run:  python tools/optimize_images.py
  3. Commit and push the changed files in images/ and portfolio/gallery-images.js

Gallery slides are picked up automatically. For the home page hero,
add or remove the matching <div data-img="images/heroN"> line in index.html.
